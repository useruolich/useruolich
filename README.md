# Hi, I'm Ali Mirza

MSc student in Transportation Economics (specialization: Statistics) at TU Dresden. I work with regional and spatial data, panel econometrics and reproducible data pipelines in R and Python.

## Projects

- **[used-car-spatial-dependence-australia](https://github.com/useruolich/used-car-spatial-dependence-australia)**: R analysis of spatial autocorrelation in used-car prices across 478 Australian cities (Empirical Bayes shrinkage, global and local Moran's I).
- **[regional-innovation-spillovers-europe](https://github.com/useruolich/regional-innovation-spillovers-europe)**: R code of a group paper on the determinants of patenting in about 240 European regions and the distance over which R&D spillovers reach (panel models, distance-band regression).
- **[bank-marketing-multivariate-analysis](https://github.com/useruolich/bank-marketing-multivariate-analysis)**: R course project on bank telemarketing data: PCA, factor analysis and classification (trees, logit, LDA/QDA, random forest).
